# HỆ THỐNG QUẢN LÝ TUYỂN DỤNG THÔNG MINH (SMARTATS)

Website **ATS (Applicant Tracking System) – Hệ thống quản lý tuyển dụng thông minh**, giúp doanh nghiệp quản lý toàn bộ quy trình tuyển dụng từ tạo yêu cầu tuyển dụng, đăng tin, tiếp nhận hồ sơ, tự động đọc CV, sàng lọc ứng viên, duyệt hồ sơ, lên lịch phỏng vấn, đánh giá đến báo cáo kết quả tuyển dụng.

Toàn bộ mã nguồn và hướng dẫn chi tiết nằm tại thư mục [ats-system](./ats-system).

## Xem tài liệu hướng dẫn chi tiết
👉 [Tài liệu hướng dẫn sử dụng & cài đặt hệ thống SmartATS (ats-system/README.md)](./ats-system/README.md)

## Cách chạy nhanh hệ thống:
1. Mở thư mục `ats-system`
2. Mở trực tiếp file `index.html` trong trình duyệt web (Chrome, Edge, Firefox), hoặc:
3. Chạy lệnh:
   ```bash
   cd ats-system
   npm start
   ```
4. Truy cập: `http://localhost:3000`
